（一）mini-vue之ast树的生成和编译

发表于2026-06-04|更新于2026-06-08|前端vue
|浏览量:

本项目参考 mini-vue 项目，实现 ast 树的生成和编译。文章仅个人见解。

本功能核心是 compileToFunction 函数，它接收 template 字符串和编译选项，返回 render 函数。

1. template处理

  1. 当 template 不为字符串且是一个 HTMLElement 时，使用该元素的内容（innerHTML）作为模板。
  2. 当 template 不为字符串也不是 HTMLElement 时，跳过处理返回一个 NOOP 函数。
  3. 继续执行后续步骤。
graph TD
    A[输入template] --> B
    B{是否为字符串} --否--> C{是否为HTMLElement}
    C --是--> D[使用innerHTML作为模板]
    C --否--> E[返回NOOP函数]
    B --是--> F[继续流程]
    D --> F
    E --> G[结束]

2. 合并编译选项

  1. 合并 options 与默认编译选项。
  2. 继续执行后续步骤。

3. 处理 customElement

4. 编译 template

4.1 生成 ast 树

  1. 首先判断 template 是否为字符串，如果是则进行转译，如果不是则将其直接作为 ast 树。
  2. 创建编译上下文，将 template 转为对象{ source: template }
  3. 将转换的对象交给 parseChildren 函数，递归解析子元素。
    • 通过消费 template 字符串，解析出不同节点
      • TEXT 文本节点
      • INTERPOLATION 插值节点
      • SIMPLE_EXPRESSION 简单表达式节点
      • ELEMENT 元素节点
      • COMPOUND_EXPRESSION 复杂表达式节点
  4. 将转换完成的 ast 树交给 createRoot 挂载到 ROOT 根节点 上
  5. 注册节点增强函数。
    • 增强元素节点
      • 指定 CREATE_ELEMENT_VNODE 运行时函数
      • 生成 codegenNode 对象
      • 返回增强函数
    • 增强文本节点
      • 将相邻的文本节点和插值节点合并为一个复合表达式节点COMPOUND_EXPRESSION，使用 ‘+’ 连接
      • 返回增强函数
    • 增强插值节点
      • 将插值结点的内容转为_ctx.${context}，如{{ msg }} 转换为 _ctx.msg
  6. 创建 transform 上下文
  7. 递归ast树节点
    1. 递归ast树为每个节点调用增强函数并收集返回的增强函数调用后返回的回调函数
    2. 处理节点
      • 插值节点：为插值节点注册运行时函数 TO_DISPLAY_STRING
      • 根节点、元素节点：继续递归处理子节点
    3. 为每个节点逆序调用回调函数
  8. 提升根节点上唯一子节点的 codegenNode 为根节点的 codegenNode 作为代码生成的入口（本项目暂时不支持多根节点模式）
  1. 将上下文的 helpers 注册到 root 的 helpers
  2. 根据增强后的 ast 树生成 render 函数
    1. 创建代码生成时的上下文对象，主要包含运行时名称、添加行、删除行、添加代码以及最终生成的代码字符串
    2. 根据不同模式生成运行时函数导入代码
      • module模式：生成 import 风格的导入语句
      • function模式：直接从全局变量解构
    3. 递归将ast树节点解析为运行时代码

5. 流程图

graph TD
    A[compileToFunction 接收 template 和 options] --> B{template 是否为字符串?}
    B -->|否| C{是否为 HTMLElement?}
    C -->|是| D[使用 innerHTML 作为模板]
    C -->|否| E[返回 NOOP 函数]
    B -->|是| F[合并编译选项 options]
    D --> F
    F --> G[处理 customElement 兼容 webComponent]
    G --> H[开始编译 template]
    H --> I[template 是字符串?]
    I -->|是| J[转译 template 字符串]
    I -->|否| K[直接作为 AST 树]
    J --> L[创建编译上下文 source: template]
    K --> L
    L --> M[parseChildren 递归解析子元素]
    M --> N[解析节点类型]
    N --> O[TEXT 文本节点]
    N --> P[INTERPOLATION 插值节点]
    N --> Q[SIMPLE_EXPRESSION 简单表达式]
    N --> R[ELEMENT 元素节点]
    N --> S[COMPOUND_EXPRESSION 复合表达式]
    O --> T[createRoot 挂载到 ROOT 根节点]
    P --> T
    Q --> T
    R --> T
    S --> T
    T --> U[注册节点增强函数 nodeTransforms]
    U --> V1[增强元素节点: 指定 CREATE_ELEMENT_VNODE 生成 codegenNode]
    U --> V2[增强文本节点: 合并相邻文本/插值为 COMPOUND_EXPRESSION]
    U --> V3[增强插值节点: msg 转为 _ctx.msg]
    V1 --> W[创建 transform 上下文 helpers Map]
    V2 --> W
    V3 --> W
    W --> X[递归 AST 树节点]
    X --> X1[为每个节点调用增强函数 收集回调]
    X1 --> X2[处理节点: 插值注册 TO_DISPLAY_STRING 根/元素递归子节点]
    X2 --> X3[逆序调用回调函数]
    X3 --> Y[提升 codegenNode: 唯一子节点 → 根节点]
    Y --> Z[注册 helpers 到 root]
    Z --> AA[生成 render 函数]
    AA --> AA1[创建代码生成上下文]
    AA1 --> AA2{生成模式?}
    AA2 -->|module 模式| AA3[生成 import 风格导入语句]
    AA2 -->|function 模式| AA4[从全局变量解构]
    AA3 --> AA5[递归解析 AST 节点为运行时代码]
    AA4 --> AA5
    AA5 --> AB[返回 render 函数]
